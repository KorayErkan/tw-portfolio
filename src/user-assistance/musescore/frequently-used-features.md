# Frequently used features

*Applies to MuseScore 3.6.2. Menu names and some shortcuts are different in MuseScore 4.*

While you create scores, you will often use the following features. You can reach them from the menus or with keyboard shortcuts.

| Feature | Menu location | Shortcut |
|---|---|---|
| Add, remove, or reorder instruments | **Edit** > **Instruments** | <kbd>I</kbd> |
| Onscreen piano keyboard | **View** > **Piano Keyboard** | <kbd>P</kbd> |
| Transpose the score or a selection | **Tools** > **Transpose** | — |
| Sound mixer | **View** > **Mixer** | <kbd>F10</kbd> |
| Page size | **Format** > **Page Settings** | — |
| Zoom | **View** > **Zoom In** / **Zoom Out** | <kbd>Ctrl</kbd>+<kbd>+</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> |
| Insert a measure before the selection | **Add** > **Measures** > **Insert One Measure** | <kbd>Ins</kbd> |
| Add a measure at the end of the score | **Add** > **Measures** > **Append One Measure** | <kbd>Ctrl</kbd>+<kbd>B</kbd> |
| Browse every symbol and build custom palettes | **View** > **Master Palette** | <kbd>Shift</kbd>+<kbd>F9</kbd> |

Symbols for articulation, dynamics, barlines, and so on are in the palettes in the left panel.

| Symbols | Palette |
|---|---|
| Dynamics, from *ppp* to *fff* | **Dynamics** |
| Staccato, tenuto, accent, and other articulations | **Articulations** |
| Repeat signs, codas, and segnos | **Repeats & Jumps** |
| Double, final, and other barlines | **Barlines** |
| Hairpins, voltas, and pedal marks | **Lines** |
| Clefs | **Clefs** |
| Time signatures | **Time Signatures** |
| Key signatures, around the circle of fifths | **Key Signatures** |

During note input, these keys set durations, add phrasing marks, and adjust pitch.

| Action | Key |
|---|---|
| Add a tie to the next note of the same pitch | <kbd>+</kbd> |
| Choose a duration (for example, <kbd>5</kbd> = quarter note) | <kbd>1</kbd>–<kbd>9</kbd> |
| Enter a rest | <kbd>0</kbd> |
| Enter a tuplet (for example, <kbd>Ctrl</kbd>+<kbd>3</kbd> = triplet) | <kbd>Ctrl</kbd>+<kbd>2</kbd>–<kbd>9</kbd> |
| Add a slur | <kbd>S</kbd> |
| Raise or lower the selected note by a semitone | <kbd>Up</kbd> / <kbd>Down</kbd> |
| Raise or lower the selected note by an octave | <kbd>Ctrl</kbd>+<kbd>Up</kbd> / <kbd>Ctrl</kbd>+<kbd>Down</kbd> |

To move a whole passage or score to another key, use **Tools** > **Transpose** instead of the arrow keys.
