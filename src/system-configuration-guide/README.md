# System Configuration Guide (Portfolio Sample)

**Audience:** System administrators, network engineers, and IT professionals
**Purpose:** Provide comprehensive system setup guidance covering server sizing, networking, certificates, and licensing requirements.

## What's Inside

- **[System Configuration Guide](system-configuration-guide.md)** — Configuration and administration guide for a fictitious Windows server product (Nordvale Server), covering hardware sizing, network and reverse proxy setup, licenses and certificates, initialization, seat provisioning, troubleshooting, and decommissioning

## Highlights

- Prerequisites by license edition, with port and firewall requirements for a single, clearly stated reverse proxy model
- Numbered GUI and CLI procedures with expected output after each step
- License editions, user roles, and certificate requirements
- Error reference table and diagnostic commands for performance, network, and certificate problems
- Ordered decommissioning procedure with backup and cleanup steps
