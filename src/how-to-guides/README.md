# How-To Guides (Portfolio Samples)

- **Audience:** Practitioners who already know the tool and need to reach one specific goal
- **Purpose:** Take the reader from a stated goal to a verified result in the fewest steps, with the risks named where they occur.

Unlike the [tutorials](../tutorials/), these guides don't teach a tool from the start. They assume the reader knows it and solve one task.

## What's Inside

- **[How to Back Up a Live SQLite Database](back-up-a-live-sqlite-database.md)** ([PDF](back-up-a-live-sqlite-database.pdf)) — Why copying the database file loses data, a comparison of `.backup` and `VACUUM INTO`, verifying and restoring a backup, and a troubleshooting table

## Highlights

- One goal per guide, with prerequisites stated up front
- Every command run and checked against a sample database, which the guide includes
- Trade-offs in a comparison table, so the reader can choose a method
- Warnings placed at the step where the risk occurs
