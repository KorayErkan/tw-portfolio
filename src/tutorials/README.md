# Tutorials (Portfolio Samples)

**Purpose:** Provide progressive, hands-on learning experiences that build understanding through practical examples and structured exercises.

- **[Command-Line Tutorial](command-line-tutorial.md)** — PowerShell 7 tutorial covering listing and filtering files, piping, formatting output, variables, and text search, all run against one sample folder

## Highlights

- Progressive learning structure from basic concepts to advanced applications
- Practical, reproducible examples with expected outputs
- Real-world scenarios and professional workflow integration
- Clear explanations of when and why to use specific techniques
- Troubleshooting guidance and best practices
